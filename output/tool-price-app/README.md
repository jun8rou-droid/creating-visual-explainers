# 🔧 工具費くらべ

町工場向けの工具価格管理アプリです。
工具の写真・納品書・見積書から**AIで工具情報と購入情報を読み取り**、工具ごと・工具屋ごとに購入価格と購入履歴を管理できます。

**公開URL: https://kouguhi-kurabe.surge.sh** （スマホのホーム画面に追加して使うのがおすすめ）

- 単一HTMLファイル（サーバー不要）＋ AI-OCR用のVercelサーバーレス関数
- データは**端末のブラウザ内（IndexedDB）**に保存。写真も含めて外部送信なし（AI読み取り時のみ、その写真をAPI経由で解析）
- スマホ=下部タブ／PC=左サイドメニューのレスポンシブ対応

## 登録のしかた

### AI読み取り（納品書・ラベル向け）
1. 📷ボタン → 写真を撮る
2. 「🤖 AIで詳しく読み取る」を押す
3. **確認画面**で読み取り結果をチェック（信頼度を🟢高/🟡中/🔴低で色分け。低い項目は要確認）
4. 間違いを直して「💾 保存」。似た品番があれば「既存の履歴に追加」か「別工具として登録」を選択
5. あとで確認したい時は「📝 下書き保存」（登録画面から再開可能）

### かんたん登録（従来方式）
写真→品番候補タップ（青=品番欄へ/グレー=価格欄へ）→価格→工具屋タップ→保存。
税区分（税別/税込）・個数・伝票番号・用途メモも入力できます。

### 価格の再登録（再購入時）
工具詳細の「➕この品番の価格を追加」→ 価格と工具屋だけで登録完了。前回の単価・購入日・個数が表示されます。

## 税込・税別の扱い
登録時に税区分を記録し、**比較・集計はすべて「税別換算単価」で統一**しています（税込は÷1.1で割り戻し、「税込→換算」バッジを表示）。税込と税別をそのまま混ぜて比較することはありません。

## AI-OCRのセットアップ（管理者向け・初回のみ）

AI読み取りにはAnthropic APIキーが必要です（従量課金・写真1枚あたり数円程度）。

1. https://console.anthropic.com にアクセスしてアカウント作成（Googleログイン可）
2. 「API Keys」→「Create Key」でキーを発行（`sk-ant-...`をコピー）
3. 「Billing」でクレジットを購入（$5から）
4. https://vercel.com のダッシュボード → プロジェクト `creating-visual-explainers` → Settings → Environment Variables
5. Key: `ANTHROPIC_API_KEY` / Value: 発行したキー を追加して Save
6. Deployments → 最新のデプロイ → 「Redeploy」

キー未設定の間もアプリは使えます（AIボタンだけ「AI未設定」エラーになり、通常OCR・手入力で登録できます）。
**APIキーはVercelの環境変数のみに保存され、アプリのコードや端末には含まれません。**

## データ管理

- **バックアップ**: ⚙️設定 →「バックアップを保存」で写真込みの1ファイル（JSON）に書き出し。「復元」で完全復元。旧形式(v1)のバックアップも読み込めます。**週1回の保存を推奨**
- **CSV出力**: 工具マスター／工具屋マスター／購入履歴（UTF-8 BOM付き・Excelでそのまま開けます）
- **CSV取込**: 購入履歴CSV（UTF-8/Shift_JIS自動判別）。取込前プレビューでエラー行・重複候補を表示し、エラー行はスキップ

## データベース設計（IndexedDB v2: `toolPriceDB`）

| ストア | キー | 内容 |
|--------|------|------|
| `tools` | partNumber | 工具マスター：工具名・メーカー・カテゴリ・サイズ・材質・コーティング・用途・メモ |
| `suppliers` | id | 工具屋マスター：名前・担当者・電話・メール・住所・支払条件・締日・支払日・Web・備考 |
| `prices` | id | 購入履歴：品番・supplierId・購入日・単価(整数円)・個数・税区分・税率・伝票番号・登録方法(ocr/manual/csv)・画像 |
| `images` | id | 写真Blob（長辺1280pxへ自動縮小） |
| `ocrDrafts` | id | AI読み取りの下書き（画像・生テキスト・構造化結果・信頼度） |
| `meta` | name | カテゴリ一覧・入力候補・移行フラグ |

- 金額は整数円で保存（浮動小数点誤差なし）。小計・合計は表示時に計算
- v1からの移行は初回起動時に自動実行（既存データは失われません）

## 技術構成
- フロント: 単一HTML（HTML/CSS/JS内包）、IndexedDB、Tesseract.js（端末内OCR）、SVG自作グラフ
- AI: Vercel Serverless Function `api/ocr.js` → Claude API（Vision）。項目別信頼度付きJSONを返却
- セキュリティ: APIキーは環境変数のみ／CORS制限／画像形式・サイズ検証／エラーに内部情報を出さない
- デプロイ: surge.sh（本体）＋ Vercel（API・GitHubプッシュで自動デプロイ）

## ローカルで動かす

```bash
npx serve -p 3030 .
```

http://localhost:3030 を開く。初回は設定→サンプルデータ、またはホームの「サンプルデータを入れて試す」で動作確認できます。
